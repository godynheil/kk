# Contributing to kk

Thank you for contributing to kk. Contributions are accepted under the
Developer Certificate of Origin 1.1 and the project license.

## Sign-off required

Every commit must include a DCO sign-off line:

```text
Signed-off-by: Name <email@example.com>
```

Use Git's `-s` flag to add it automatically:

```bash
git commit -s -m "type(scope): describe the change"
```

By signing off, you certify the contribution under the Developer
Certificate of Origin 1.1 in [DCO.md](DCO.md).
